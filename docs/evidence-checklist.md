# Danh sách minh chứng còn cần bổ sung từ máy và tài khoản nhóm

- [ ] Tên nhóm, họ tên các thành viên, lớp, Project Lead.
- [ ] `code --version` (hoặc ảnh About trong VS Code), `g++ --version` / MSVC, `cmake --version`, `git --version` trên **máy của sinh viên**.
- [ ] Ảnh VS Code mở đúng thư mục dự án.
- [ ] Ảnh chạy `test.cpp` và ứng dụng V0.1.0 trên máy nhóm.
- [ ] URL GitHub/GitLab Repository do nhóm tạo và quyền truy cập của các thành viên.
- [ ] Git branch `main`, `develop`, `feature/project-setup`; các commit thực tế.
- [ ] Ảnh Pull Request từ `feature/project-setup` vào `develop`.
- [ ] Hai nhận xét Code Review của thành viên khác.
- [ ] Pull Request đã merge, tag/release `v0.1.0` đúng commit đã kiểm tra.
- [ ] TC08: ảnh clone từ GitHub/GitLab và build lại thành công trên thư mục/máy khác.
- [ ] Cập nhật bảng kết quả TC01–TC08 theo kết quả trên máy nhóm.

Không đánh dấu **Đạt** thay cho một bước chưa được thực hiện.
